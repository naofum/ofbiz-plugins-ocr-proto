# ofbiz-plugins-ocr-proto

Apache OFBiz 向けの OCR プラグイン。  
OFBiz に OCR 機能を追加し、他のアプリケーションやプラグインから呼び出して利用する OCR の汎用基盤を提供する。

---

## 概要

他のアプリケーションやプラグインから共通の OCR 機能を利用できるようにする。

OCR は、プラグイン単独で利用できる Tesseract と、外部の OpenAI 互換 API で呼び出すマルチモーダルの AI モデルを利用する、あるいは両方一緒に使う方法がある。  
Tesseract は外部にデータを送信しないので安全を求めるケースで用い、文字認識精度を求める場合は AI モデルを利用することになる。  
さらに、AI モデルを利用する場合は、項目をマッピングして取得することも可能になる。例えば請求書の請求金額を出力パラメータの請求金額としてマップするなど。  
それぞれアプリケーションのユースケースにより使い分けることができる。  
また、それぞれの場合で、本サービスの呼び出し方法、インターフェースなどは共通化する。

## 対象ドキュメント

文書タイプは限定しない。任意の画像または PDF から以下の2段階で情報を取得する。

1. **テキスト抽出**: 画像または PDF から生のテキストを取得する。
2. **構造化データ抽出**: 画像または PDF から、あらかじめ定義した項目（マッピング定義）に従って構造化データを取得する。

## 項目マッピング

AI モデルに対して「何が欲しいか」をプロンプトで指定する。  
各呼び出し元は以下のいずれかでマッピングを指定できる。

- `OcrMappingDefinition` の識別子を指定する。
- 呼び出し時にインラインプロンプトを直接指定する。

マッピング定義には、期待する出力項目の名前と型を含める。  
サービスは AI モデルの応答を解析し、`Map<String, Object>` として呼び出し元に返す。

## ファイルの受け渡し

基本的には OFBiz の `DataResource` / `Content` を使って画像または PDF を管理する。  
加えて、サービスの入力に `ByteBuffer` を直接受け取る方式も提供する。  
`Content` 経由のサービスと `ByteBuffer` 経由のサービスはエントリを分ける。

## UI

本プラグインは以下の UI を提供する。

- **WebUI**: 画像/PDF をアップロードし、OCR エンジンを選択して実行し、結果（生テキストおよび構造化データ）を確認できる画面。OCR の動作確認用。

## 永続化

OCR 実行結果は `OcrRequestResult` に永続化するが、呼び出し元が指定した場合のみとする。  
永続化しない場合でも、サービスの戻り値として結果を返す。

## セキュリティ

- Tesseract はローカル実行のため外部にデータを送信しない。
- OpenAI 互換 API は外部に画像データを送信する。利用時はプライバシー・セキュリティ上の注意を呼びかける。
- API キーは `OcrEngineConfig` エンティティに平文で保存する簡易版から始める。
- アクセス権限として `OCR_ADMIN`、`OCR_VIEW`、`OCR_CREATE` を定義する。
